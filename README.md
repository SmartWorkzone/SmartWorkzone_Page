# Integrated Smart Work Zone

Project website for the **Integrated Smart Work Zone** research project at Purdue University.

**Smarter and Safer Workzone Through Multimodal Intrusion Detection**

| Page | File |
|------|------|

| People | `people.html` |

| Outreach | `outreach.html` |
| Contact | `contact.html` |

## GitHub Pages

1. Push this repository to GitHub.
2. Go to **Settings → Pages** and set the source to deploy from the `main` (or `master`) branch root.
3. The site will be available at `https://<username>.github.io/<repo-name>/`.

The `.nojekyll` file is included so GitHub Pages serves all files correctly.

## Local preview

Open `index.html` in a browser, or serve the folder with any static file server.
